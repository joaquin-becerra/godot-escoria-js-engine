# godot-escoria-js-engine

A lightweight JavaScript engine that plays 2D point & click adventures made with
[Godot 4](https://godotengine.org) + [Escoria](https://github.com/godot-escoria)
in the browser, without Godot's WebAssembly runtime.

```
Godot + Escoria project  ──►  exporter (Node)  ──►  game.json + assets  ──►  JS engine (browser)
(.tscn .tres .esc ...)
```

Status: it plays from start to end the games it was built with: OpenQuest as
generated by [scumm2escoria](https://github.com/joaquin-becerra/scumm2escoria),
an enhanced version of it, and the complete
[Escoria demo game](https://github.com/godot-escoria/escoria-demo-game).
Other games may use parts of Godot or Escoria the engine doesn't have yet:
`tools/compat.js` tells which.

## Quick start

```
node tools/export.js ../my-escoria-game       # -> out/my-escoria-game/
node tools/serve.js                           # then open http://localhost:8090/player/?game=my-escoria-game
```

## Tools

Node.js 20+. The engine and the tools have no dependencies; `ffmpeg` (with
libvorbis) is optional, to turn `.wav` sounds into `.ogg` when exporting.
`tools/compare` also needs `npm install` (Playwright), a Chrome/Chromium and,
for the Godot side, the Godot 4 editor (`godot` in the PATH, or `$GODOT`).

```
node tools/inventory.js <godot project dir>   # what the project uses -> inventory/<name>.md
node tools/export.js <godot project dir>      # game for the engine -> out/<name>/ (game.json + res/)
                                              # (its GDScript translated to js_ports/ by tools/gd2js)
                                              # ends with tools/compat.js: can the engine play it?
node tools/compat.js out/<name> [-v]          # compatibility report -> out/<name>/COMPATIBILITY.txt
node tools/trace.js <exported game>           # plays its intro in Node, prints what was said and the globals
node tools/serve.js                           # http://localhost:8090/player/ (play), /viewer/ (debug)
node tools/compare/run.js --engine js|godot ...  # plays a walkthrough (tools/walkthroughs/) in either engine
node tools/compare/diff.js <out dir>          # compares both runs: state per step, side-by-side video
```

Player options (query string): `game=<name>` (the folder in `out/`),
`room=res://...tscn` and `set=global=1,other=0` to start in a room for testing,
`auto=<walkthrough.json>` to play a walkthrough by itself and
`record=<name>` to record it (`tools/serve.js` saves it in `out/videos/`, or in
`$VIDEO_DIR`).

## Notes

- GDScript is not executed: the engine reimplements Godot's 2D nodes and
  Escoria's behaviour (including its ASHES script interpreter) in JavaScript.
  A game's own GDScript is translated to JS by `tools/gd2js`; changes a game
  makes to Escoria's addons need their JS side in the project's
  `js_ports/escoria_patches.js`.
- Godot and Escoria are MIT licensed; their notices for the code ported from
  them are in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
